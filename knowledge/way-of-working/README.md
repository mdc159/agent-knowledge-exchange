# Way of Working

**Status: work in progress.** Develop a lightweight, empowering way for agents and humans to turn imperfect inputs into useful outcomes while keeping the actual objective in view.

The aim is to make the easy path the useful, responsible path: a working philosophy expressed through small defaults, practical skills and feedback from real tasks. This is a reusable design, not a new control service or a replacement for existing safety and authorization boundaries.

## Read and use

- [Way of Working](way-of-working.md): the philosophy and outcome-directed loop.
- [Adoption and experiments](adoption.md): the smallest implementation first, optional extensions and evaluation.
- [Practical engineering skill](../../skills/shared/practical-engineering-loop/SKILL.md): a compact reusable execution aid.

## What this project explores

- A small orientation in persistent instructions or automatically loaded guidance.
- Skills that supply practical procedures when needed.
- Explicit, lightweight activation so useful guidance is available without depending solely on recall.
- Optional small models for quick routing, classification or context selection, leaving deeper reasoning for work that benefits from it.
- Optional hooks at well-chosen points, introduced only when a real workflow benefits.

The philosophy is the stable center; implementation is open to improvement. Start with the least machinery that works and evaluate it through use. A prompt, skill, classifier and hook can complement each other without all being prerequisites.

## Contribution and scope

Contribute sanitized examples, small experiments and observed outcomes through the repository's normal review process. Keep private conversations, operator identities, infrastructure and operational handoffs in their private project homes.

This directory intentionally uses an ordinary philosophy document rather than a nested `AGENTS.md`: reading a proposal should not silently activate it as policy in a new runtime. Adoption is explicit. Repository-level agent instructions continue to govern contributions here.
